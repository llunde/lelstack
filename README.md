# 🧰 lelstack

A collection of workflows, skills and tooling for working with AI agents and LLMs.

## Contents

- 🧝‍♂️ [**elrond**](elrond/): a template for building software with an LLM agent in a resumable plan → implement → verify loop.

- 🧙‍♂️ [**gandalf**](gandalf/): an agent workflow for everyday tasks across many repos: install once in a workspace, then intake → branch → implement → verify → review → PR from any repo below it.

- 🧩 [**skills**](skills/): skills I author, picked up by the workflow or used on their own, plus `harvest` for capturing what a project taught.

- 📜 [**prompts**](prompts/): copy-paste prompts I reuse and keep improving.
